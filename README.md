## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `isaac-kwizera`.
2. Upload `index.html` and `styles.css`.
3. Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/root`.
6. Save.

Before publishing, replace the placeholder email and LinkedIn URL in `index.html`.
