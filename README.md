## Publish with GitHub Pages
1. Create (or reuse) a public repository, e.g. `Isaac-K`.
2. Upload `index.html`, `styles.css`, and (once added) the CV PDF directly to the repo root — not inside a subfolder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Set branch to `main`, folder to `/ (root)`, then **Save**.
6. Your site will be live at `https://<username>.github.io/<repo-name>/` within a couple of minutes.
